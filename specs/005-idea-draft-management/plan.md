# Implementation Plan: Idea Draft Management

**Branch**: `005-start-specify-run` | **Date**: 2026-05-15 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/005-idea-draft-management/spec.md`

## Summary

Implement owner-only draft management for idea preparation by adding dedicated draft persistence tables, submitter-scoped draft server actions, and dashboard resume UX. Draft saves allow empty/partial data, drafts are never visible to admins or other users, and final submission from a draft performs atomic create-and-delete so only submitted ideas remain.

## Technical Context

**Language/Version**: TypeScript 5.9 (strict mode)

**Primary Dependencies**: Next.js 15 (App Router), React 19, Drizzle ORM 0.45, Zod 4, react-hook-form 7, iron-session 8, Tailwind CSS 4, shadcn/ui

**Storage**: SQLite via better-sqlite3 + Drizzle ORM; new tables `idea_drafts`, `idea_draft_attachments`, `idea_draft_field_values`

**Testing**: Vitest + React Testing Library (unit/component), integration tests under `tests/integration`, Playwright for E2E

**Target Platform**: Web application (Node.js server + browser clients)

**Project Type**: Single Next.js full-stack application

**Performance Goals**: Draft save and update in under 1 s in local/dev; dashboard draft list render in under 500 ms for up to 100 drafts per submitter

**Constraints**: No new npm dependencies; drafts are owner-only (including admin-denied visibility); no automatic draft expiration; full submit validation still required on final submission

**Scale/Scope**: Single test-project deployment; low concurrent usage; multiple drafts per submitter; no cross-user sharing in v1
